# HT Speech – الكتابة الفورية للكلام (نسخة آيفون)

تطبيق ويب يعمل في سفاري على آيفون، يحوّل الكلام الذي يسمعه الميكروفون إلى نص مكتوب بخط كبير،
مصمَّم لضعاف السمع. فيه محركان:

- **Whisper عبر Groq (الافتراضي):** أدق للعربي المصري والإنجليزي داخل الجملة نفسها، ويلتقط الكلام الواطي
  والبعيد بتعلية تلقائية. مجاني بحدود يومية، ويحتاج مفتاحًا مجانيًا من Groq.
- **محرك Apple:** كلمة بكلمة، لغة واحدة في كل مرة، بلا مفتاح.

## أول مرة على آيفون

1. افتح الرابط في **سفاري**، ثم زر المشاركة ثم **«إضافة إلى الشاشة الرئيسية»**.
2. أنشئ حسابًا مجانيًا في `console.groq.com`، وافتح **API Keys** ثم **Create API Key**، وانسخ المفتاح.
3. في التطبيق: زر الإعدادات ⚙︎ ← الصق المفتاح ← **«حفظ المفتاح وفحصه»**.
4. لكي لا يسأل سفاري عن الميكروفون كل مرة: زر **«aA»** في شريط العنوان ← **إعدادات موقع الويب**
   ← **الميكروفون** ← **سماح**.
5. اضغط **«بدء الاستماع»**. تنبيه الخصوصية يظهر مرة واحدة فقط.

## كيف يعمل محرك Whisper

- الصفحة تأخذ إذن الميكروفون مرة واحدة وتحتفظ به طوال فتحها (الإيقاف المؤقت لا يغلقه).
- تعلية تلقائية دائمًا على أقصى مستوى + فلتر للزنّة والصفير + ضاغط يمنع تشوّه الكلام القريب.
- تكتشف بداية الجملة ونهايتها، وترسل كل جملة لوحدها؛ النص يظهر بعد انتهاء الجملة بثانية أو اثنتين،
  وتظهر «جارٍ الكتابة…» مكانها حتى يصل النص، وتبقى الجمل بترتيبها حتى لو وصلت ردودها بترتيب مختلف.
- منع الاختلاق: لا يُرسل الصمت، وتُحذف العبارات الوهمية المعروفة («اشتركوا في القناة» وأمثالها)،
  وما لا يثق فيه المحرك يُكتب **«[غير واضح]»**.

## الحدود المعروفة (بصراحة)

- **الخلفية:** آيفون يوقف الميكروفون لأي صفحة ويب عند الخروج منها إلى تطبيق آخر. عند العودة يستأنف التطبيق
  تلقائيًا ويكتب في النص الفترة التي لم تُسمع. الاستماع في الخلفية فعلًا يحتاج تطبيق آيفون أصليًا.
- **الكلام البعيد:** يُكتب إن كان مسموعًا، لكن الدقة أقل من الكلام القريب، والتعلية ترفع الضوضاء أيضًا.
- لا يميّز التطبيق بين المتحدثين.
- الخطة المجانية من Groq: نحو 8 ساعات صوت يوميًا، و20 جملة في الدقيقة، و2000 جملة يوميًا (حسب صفحة Groq).
- يحتاج إنترنت. عند الانقطاع تنتظر الجمل وتُرسل عند عودة الاتصال.

## الخصوصية

- مع Whisper تُرسل مقاطع الكلام إلى Groq عبر الإنترنت؛ مع Apple قد يُرسل الصوت إلى خوادم Apple.
- لا يُحفظ أي تسجيل صوتي. النص والمفتاح يُحفظان على الجهاز فقط.

## بنية المشروع

| الملف | الدور |
|---|---|
| `js/transcript.js` | النواة: النص والفقرات بلا تكرار ولا فقد. |
| `js/vad.js` | النواة: اكتشاف بداية الكلام ونهايته وتقطيعه جملًا. |
| `js/filter.js` | النواة: منع الاختلاق و«[غير واضح]». |
| `js/wav.js` | تحويل الصوت إلى 16 kHz وترميزه WAV. |
| `js/groq.js` | الاتصال بخدمة Groq. |
| `js/whisper_engine.js` | التقاط الصوت والتعلية والإرسال والترتيب. |
| `js/capture-worklet.js` | التقاط عينات الصوت داخل خيط الصوت. |
| `js/recognizer.js` | محرك Apple. |
| `js/app.js` | الواجهة والأزرار والإعدادات. |
| `tests/test.html` | اختبارات النواة (44 اختبارًا). |
| `tests/e2e_mocks.js` | ميكروفون صناعي وردود وهمية لتجربة الصفحة كاملة بلا مفتاح. |

النواة (`transcript.js` و`vad.js` و`filter.js`) لا تعتمد على المتصفح، فتُعاد كما هي في أي نسخة لاحقة.

## التشغيل محليًا للتطوير

```powershell
python -m http.server 8795 --bind 127.0.0.1 --directory "H:\HT Speech\iphone"
```

## قائمة التحقق على الآيفون

| الحالة | ما المطلوب ملاحظته |
|---|---|
| كلام مصري عادي | العامية تُكتب كما قيلت. |
| جملة مختلطة | الكلمة الإنجليزية تبقى بحروفها الإنجليزية. |
| صمت دقيقة كاملة | لا يظهر أي نص. |
| ضوضاء (تلفاز أو مروحة) | لا كلمات وهمية كثيرة. |
| كلام واطي، وكلام من غرفة مجاورة | هل يُكتب؟ وما دقته؟ |
| الخروج لتطبيق آخر ثم العودة | يستأنف وحده ويكتب الفترة التي لم تُسمع. |
| إيقاف مؤقت ثم استئناف | لا يُطلب إذن الميكروفون مرة أخرى. |
| جلسة 30 دقيقة | لا توقف ولا تكرار ولا جمل ناقصة. |
