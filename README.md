# HT XER-Audit

A completely free, non-profit Windows program to analyse, compare and update Primavera P6 schedules from an XER file.

برنامج مجاني بالكامل وغير هادف للربح لتحليل برامج Primavera P6 الزمنية ومقارنتها وتحديثها من ملف XER.

**Download / التحميل:** see [Releases](../../releases/latest).

This repository holds the program's website and its download files. The program's source code is not published here.

Primavera and P6 are trademarks of Oracle. HT XER-Audit is an independent program, not connected with Oracle.
